# Commit messages

All new commit messages must be written in English and use an appropriate Conventional Commits prefix.

Format: `type: concise description` or `type(scope): concise description`.

Choose the type that describes the change: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, or `revert`.

Examples:

- `feat: add quiet looping background music`
- `fix: keep music controls in sync during playback`
- `docs: document portfolio setup`
